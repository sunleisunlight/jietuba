# v2.8.0 macOS 适配

> 本文件是本轮适配过程中的历史草稿，不代表已发布的 v2.8.0。实际交付版本为 [v2.8.1](v2.8.1-macos.md)。

- macOS 全局快捷键接入共享的禁用状态与优先级处理，保持 Windows 原生热键实现。
- 系统权限页显式请求屏幕录制、辅助功能与输入监控，自动刷新权限状态。
- 修复多显示器边界枚举、钉图鼠标穿透，以及目标未激活时误向其它应用粘贴的问题。
- 修复 ScreenCaptureKit 启动失败/超时状态、回调生命周期与帧尺寸校验，录屏排除应用自身窗口。
- Mac 更新使用真实 arm64 架构查询，下载校验后验证应用身份和 Apple 签名，退出后安装并保留旧版备份。
- 提供 Mac arm64 的 app.tar.gz、同名签名、DMG、更新说明四件套；历史发布文件保持不变。
- Mac Qt 依赖锁定兼容 macOS 12 的版本，Windows 依赖不变；修复安装脚本中文变量边界。
