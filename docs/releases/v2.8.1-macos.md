# v2.8.1 macOS 适配与品牌统一

- macOS 应用、设置窗口、菜单栏和发布包统一使用 Windows 正式版名称“积磊截图”。
- 使用 Windows 正式 `托盘.ico` 的最大分辨率图层生成 macOS `.icns`，避免低分辨率旧图标被放大。
- 保留 `cc.jilei.jileiscreenshot` Bundle ID 与 `JileiScreenshot` 内部可执行文件名，兼容已有数据、权限和更新链路。
- macOS 全局快捷键接入共享的禁用状态与优先级处理，保持 Windows 原生热键实现。
- 系统权限页显式请求屏幕录制、辅助功能与输入监控，自动刷新权限状态。
- 修复多显示器边界枚举、钉图鼠标穿透，以及目标未激活时误向其它应用粘贴的问题。
- 修复 ScreenCaptureKit 启动失败/超时状态、回调生命周期与帧尺寸校验，录屏排除应用自身窗口。
- Mac 更新使用真实 arm64 架构查询，下载校验后验证应用身份和 Apple 签名，退出后安装并保留旧版备份。
- 提供 Mac arm64 的 app.tar.gz、同名签名、DMG、更新说明四件套；历史发布文件保持不变。
- Mac Qt 依赖锁定兼容 macOS 12 的版本，Windows 依赖不变；修复安装脚本中文变量边界。

## 验证与分发边界

- 已构建真实 arm64 应用及四件套，应用版本、菜单名称与 Windows 同源橙色图标已在本机界面核对。
- 应用签名校验、DMG 完整性、OCR 模型和 Rust 扩展打包检查通过。
- 两组针对性测试共 85 项通过、3 项 Windows 专属测试跳过；这不等同于全功能人工验收。
- 最终打包应用的权限页显示屏幕录制、辅助功能、输入监控均已授权。
- 当前为 Apple Development 签名，未完成 Developer ID 签名及公证，不代表 Gatekeeper 对外分发验收通过。
- Windows 实机、完整截图/OCR/GIF/多屏及应用内更新端到端流程仍需人工验收；本分支不自动合回 main。
