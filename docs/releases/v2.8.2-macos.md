# v2.8.2 macOS 启动与平台基础修复

- 普通打开 Mac 应用会显示设置入口；登录自启使用独立静默模式。
- 重复启动通过本机单实例通道唤起原窗口，不再强制终止原进程；保留截图编辑及模态窗口。
- Dock 再次打开应用时恢复可操作入口，关闭设置后继续常驻菜单栏。
- 修复开机自启登记失败、路径特殊字符和设置窗口误调用 Windows 任务栏接口的问题。
- 权限未授予和原生权限查询失败分别反馈，检查失败时停止截图，不继续生成无效结果。
- 保留 Windows 同源品牌图标、应用内部身份、现有设置与历史数据。
- 修复 Windows 英文区域设置下中文桌面快捷方式迁移/创建失败，使用原生 Unicode 接口；保留单实例通信所需的打包依赖。

本轮为任务1候选。构建与单元测试不代替 Windows 门禁、打包 App 实测或 Developer ID 公证；具体进度见 docs/macos-parity/STATE.md。
